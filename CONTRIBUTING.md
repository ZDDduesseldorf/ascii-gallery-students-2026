# Contributing

Dieses Repository wird im Kurs absichtlich über einen **shared-repository / feature-branch workflow** bearbeitet.

1. Kein direkter Push nach `main`.
2. Für jede Aufgabe ein Issue.
3. Für jedes Issue ein eigener Branch.
4. Kleine, nachvollziehbare Commits.
5. Pull Request gegen `main`.
6. Mindestens ein Peer Review vor dem Merge.
7. Bei neuen Commits Review-Kommentare erneut prüfen.

Die ASCII-Art muss für eine öffentlich sichtbare Kursseite geeignet sein. Bitte auch keine sensiblen personenbezogenen Daten verwenden.
